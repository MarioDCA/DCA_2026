# Kvizi - Osnove računalništva in umetne inteligence

## 📚 O projektu
Zbirka 26 interaktivnih kvizov za učenje osnov računalništva in umetne inteligence.

## 🎯 Kategorije
- 🟢 **Za začetnike** (OR_01 - OR_10) - Osnovni pojmi
- 🟡 **Srednja zahtevnost** (OR_11 - OR_18) - Poglobljeno znanje
- 🔴 **Za napredne** (OR_19 - OR_26) - Napredne teme

## 🚀 Kako uporabljati
1. Odpri `index.html` v brskalniku
2. Izberi kviz glede na tvoje znanje
3. Rešuj vprašanja in spremljaj napredek
4. Na koncu dobiš oceno in povratno informacijo

## 💾 Shranjevanje napredka
Podatki o rešenih kvizih se shranijo v tvoj brskalnik (LocalStorage).
